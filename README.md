# Backpack Legions

Unity ile geliştirilen, kule savunmasını kuleye özel çanta ve eşya yerleşimiyle birleştiren oyun prototipi.

## Projeyi açma

- Unity Hub üzerinden **Unity 2022.3.62f3** ile bu klasörü açın.
- `Assets`, `Packages` ve `ProjectSettings` birlikte korunmalıdır; asset `.meta` dosyaları depoya dahildir.
- Unity ilk açılışta paketleri ve Library klasörünü yeniden oluşturur.
- Başlangıç sahneleri `Assets/Scenes` altındadır; etkin sahneler Build Settings içinde kayıtlıdır.
