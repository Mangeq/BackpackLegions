# Cinzel Bold and Alegreya Medium

Official Google Fonts sources were downloaded with their SIL Open Font License files, retained under ArtSource/Fonts. Tools/UI/install_game_fonts.py creates static font instances for Unity 2022: Cinzel weight 700 (Bold), Alegreya weight 500 (Medium). Files and redistribution licenses are included under Assets/Resources/UI/Fonts.

GameFonts exposes shared title/body TMP assets and legacy Unity Font sources. The main atlases are static, sampled at 80 with padding 8 in 2048-square textures. They bake 319 Cinzel and 443 Alegreya source-supported Latin/punctuation glyphs, including all Turkish letters and numbers. Liberation Sans remains a symbol fallback. Runtime tower panels now reuse these assets instead of generating and later destroying their own dynamic fonts.

GameFontsBuilder migrates editable TMP and legacy text in all UI prefabs, the three build scenes and the currently open scene. It also updates serialized font fields used by skins to create future labels. Runtime/editor reference builders use GameFonts consistently. Title/action labels use Cinzel; subtitles, descriptions and statistical values use Alegreya. Small skill-node names use bounded sizing (8–10) to fit longer Turkish labels. The approved artwork, logos and lettering already painted into image textures remain unchanged; this migration changes actual font-based UI text.

Eight live checks passed (results.json): static Turkish atlas coverage, scene bindings, chapter headings/details, runtime skill-node/tab labels, runtime HUD, shared tower assets, future item badge sources and safe shared-font lifetime. Chapter and skill previews have no reported text overflow. TMP reports some inventory fields as exceeding their original layout rects vertically; the verified screenshot uses their existing Overflow mode and shows the complete values without clipping. Screenshots: chapter-fonts.png, skill-fonts.png, inventory-fonts.png. Source weight metadata confirmed 700 and 500; Unity face names confirmed Bold and Medium. Tests did not change persistent player settings or rewards. Original editor scene and start preference restored; scene stopped and clean. Before snapshots preserve each edited scene/prefab.
