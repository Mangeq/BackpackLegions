# Haftalık proje paylaşımı

Kullanıcının 3 Ekim 2026 talebi: özel GitHub deposu, düzenli proje güncellemesi ve kişisel LinkedIn profilinde Türkçe haftalık ilerleme paylaşımı; her gönderiye 1–2 gerçek oyun ekran görüntüsü.

- Program: GitHub her gün 18.00; LinkedIn cuma 18.00, Europe/Istanbul. (16 Ekim 2026 kullanıcı tercihi.)
- GitHub özel deposu: https://github.com/Mangeq/BackpackLegions ; origin: https://github.com/Mangeq/BackpackLegions.git .
- LinkedIn kişisel profili: Emir Çalışkan, https://www.linkedin.com/in/emir-%C3%A7-061011267/ .
- GitHub güncellemesi: günlük çalışmada anlamlı proje değişikliklerini incele, commit et ve normal push yap. Force push yapma; başka çalışmaları ezme.
- GitHub günlük sonuçlarını commit SHA ve zamanla `Docs/DailyUpdates/YYYY-MM-DD/status.json` içinde kaydet. Değişiklik yoksa boş commit oluşturma.
- LinkedIn haftalık karşılaştırmasını son başarılı LinkedIn paylaşımından başlat; günlük GitHub commitleri bu başlangıcı değiştirmez.
- LinkedIn: o haftanın doğrulanmış geliştirmelerini 3–5 kısa maddeyle, doğal Türkçeyle anlat. Tarihsiz eski raporları haftalık yeni ilerleme sayma. Henüz uygulanmamış hedefleri ayrı belirt.
- Ekran görüntüleri: güncel oyundan 1–2 görüntü al; hangi yeniliği gösterdiğini kontrol et. Yapay görseli oyun ekran görüntüsü olarak sunma. Görüntü alınamıyorsa gönderiyi taslak olarak sakla ve engeli bildir.
- Her haftanın taslağını, kanıt notlarını ve görsellerini `Docs/WeeklyUpdates/YYYY-MM-DD/` altında sakla.
- Gönderi başarıyla yayımlandığında URL, tarih, görsel yolları ve ilgili Git commit SHA bilgisini aynı klasördeki `status.json` dosyasına kaydet.
- GitHub push ve LinkedIn yayımlama sonuçlarını ayrı kaydet. Hata alan adımı başarılı işaretleme. Yeniden denemede önceden gönderilmiş içeriği tekrar yayımlama; belirsiz sonuçta profil akışını kontrol et.
- Anlamlı yeni ilerleme yoksa paylaşım üretme ve sessiz kal. Başarı, anlamlı hata veya kullanıcı müdahalesi gerektiğinde bildir.
- Gizli depo dosyalarını veya özel erişim bağlantılarını LinkedIn'e ekleme. Yalnızca oyun ilerlemesi ve seçilen oyun görüntülerini paylaş.
